## 已导入教材的标注

对派生章节 TXT，服务端仅采用与知识库 ID、文档 ID、Chunk ID、内容哈希匹配的本地来源记录。旧 `page`、派生文本页和未核实的小节不再作为定位；缺少经审查的 `verified_printed_page` 时显示页码未知。同一文档、同一已知页、同一节的多个引用可在界面共用一张位置卡，各自的锚点与 API 证据原样保留。页码未知的不同引用保留独立卡片。

核对当前 V1→V2 导入映射、教材版次和 Chunk 内容后，可在服务器现有私有标签文件内，为匹配项填写 `verified_printed_page`、`verified_section_title`。只改展示标签不需要重导入或向量化。包含多个未能确认原文定位的源记录时保持未知。若未来确需更正正文，再独立审查授权并走正常重新导入和索引流程。历史回答中已保存的旧标签需要另行回填或重新提问，本次不写入历史数据。
