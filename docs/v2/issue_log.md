# V2 功能验收问题记录表

## 1. 使用说明

本表用于记录 V2 功能验收过程中实际发现的问题，以及影响测试执行的阻塞事项。

- `OPEN`：问题已确认，尚未解决。
- `IN_PROGRESS`：正在处理。
- `RESOLVED`：已解决，并经过验证。
- `BLOCKED`：测试或处理受到环境、权限、依赖等因素阻塞。
- `PENDING_VERIFICATION`：尚未完成验证，不能认定为缺陷。

没有实际测试证据时，不得将推测写成已确认的系统缺陷。

## 3. 问题关闭要求

问题只有在修复或处理完成，并通过相应验证后，才能标记为RESOLVED。

环境阻塞解除后，应更新相关测试用例状态并补充实际结果。不得仅因为文档已经创建，就将测试问题标记为解决。

## 4. 记录边界

不得记录密码、Cookie、API Key、完整环境变量文件或私人文档正文。截图和日志应进行脱敏处理。
