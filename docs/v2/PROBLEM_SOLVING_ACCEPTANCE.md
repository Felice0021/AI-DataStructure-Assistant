## PR 复审：构造条件与追问边界

缺条件检查先区分具体构造、原理/代码分析及明确要求自拟的示例。序列支持单个整数或单字母键、
中文逗号/顿号/空格、括号、负数和全角字符。正号及前导零规范化，避免重复键漏检；数量、区间、
小数等不支持的形式不截取成另一个键。单键从空树构造不要求无关阶数/分裂信息，但显式矛盾
的规则仍被拒绝。这里不是完整自然语言/树求解器。

B/B+ 树按用户明确的阶数/最大孩子数或 B 树最小度数检查容量。相关歧义返回
ambiguous_tree_rules；发生分裂时检查时机、左右分配和父键约定，偶数键的中位选择不能含糊。
B+ 多级分裂还需内部结点约定，否则 ambiguous_tree_split。已规定的原题左2右1规则不变；
另一种明确的左1右2例子有独立 HTTP 参考结果测试，不能静默互换。自拟示例必须在生成说明中
标注初始状态、输入与假设。前端对这些拒答提示补条件，不报告成模型故障。

仅对无重复键或明确忽略重复键的构造作自动放行；复杂重复记录放置、非空初始树、未知键格式、
复杂级联约定保守要求澄清。词法检查不证明任意给定约定在数学上自洽；模型事实、完整步骤和
来源忠实性仍需人工审核，既有 Cloud Guard 与引用校验未放宽。
