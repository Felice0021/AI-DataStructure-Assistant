## 方法与局限

1. 原 `validate_chunks.py` 原样调用，输出到新报告，结果 ERROR=0、WARNING=0。空文本、重复 ID、空白归一化后完全重复正文、无效页码类型等原校验项均未发现异常。
2. 新增只读规则：null 页码、来源同名文件缺失、替换/控制字符、ID 与 section 数字前缀不符、代码括号/注释界符数量、省略标记与公式界符。规则不是语义、OCR 或代码正确性的完整证明。
3. 近似重复：同章节、归一化正文至少25字符、长度比至少0.7，字符三元组集合 Jaccard >=0.72，命中11对22条；保留双方，不自动合并。未作跨章语义去重。
4. 候选按预设章节配额分配，优先覆盖不同小节和类型，排除规则命中项与已记录内容问题；同覆盖条件下优先较完整正文，以源顺序打破平局。本轮优先概念/算法/代码，不将未核实答案的习题纳入候选。
5. AI 阅读初始候选和替补，共130条，发现29条内容/边界疑点；每条意见保存在 `tools/course_audit/content_notes.json`，未读的880条仅标自动检查。最终100条候选全部有AI初审说明。
6. 没有逐条对照教材、运行/编译全部代码或测量 RAG 效果。资料权限依据用户会话确认，未独立核验书面凭据；用途限非商用研究试验。带“需注明”前提的候选应在教学使用说明中保留限制，不能改写原文后冒充原记录。
